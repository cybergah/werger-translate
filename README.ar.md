## 🌍 ما هو Wergêr؟

**Wergêr** (بالكردية: _«المترجم»_) هو تطبيق ترجمة **مجاني** و**مفتوح المصدر** من تطوير [**Cybergah Group**](https://cybergah.com). يعمل **دون اتصال (أوفلاين)** و**عبر الإنترنت (أونلاين)**، وهو متاح على **أندرويد** و**ويندوز**.

هدفنا بسيط: تقديم ترجمة عالية الجودة للغة **الكردية** ولغات أخرى كثيرة — بلا تكلفة، بلا إعلانات، بلا تتبّع للبيانات.

## ✨ الميزات

- 📝 **ترجمة النصوص** — كلمات وجُمل وفقرات
- 📄 **ترجمة المستندات** — ملفات `.txt` و`.pdf`
- 📷 **ترجمة الصور** — التعرّف الضوئي على الحروف (OCR)
- 🔊 **النطق الصوتي (TTS)** — قراءة الترجمات بصوت مسموع

- 🌐 **عبر الإنترنت** — عبر LibreTranslate (عنوان قابل للضبط)
- 🆓 **مجاني ومفتوح المصدر** — دائمًا، للجميع

## 🔌 دون اتصال & عبر الإنترنت

يوجد محرّكان للترجمة:

### محرّك دون اتصال — NLLB-200
- النموذج: **Meta NLLB-200 distilled 600M** (`facebook/nllb-200-distilled-600M`)
- الصيغة: **int8 ONNX** (مُكمَّم، نسخة من Xenova)
- التشغيل: **ONNX Runtime** على الجهاز (المعالج)
- المُرمِّز (Tokenizer): أُعيدت كتابة **مُرمِّز NLLB BPE** بالكامل بلغة Kotlin/Rust الصِّرفة — بلا مكتبات native، أوفلاين 100٪
- يُنزَّل النموذج (~**870 ميغابايت**) مرّة واحدة إلى مجلد باسم **Wergêr** (أو مجلد يختاره المستخدم، يُكتشف تلقائيًا). بعدها يعمل التطبيق **بلا إنترنت**.

### محرّك عبر الإنترنت — LibreTranslate
- عنوان [LibreTranslate](https://libretranslate.com/) قابل للضبط
- لمن يفضّلون عدم تنزيل النموذج

## 📥 التثبيت

### أندرويد
1. نزّل أحدث ملف APK من [**Releases**](../../releases).
2. افتح ملف `.apk` وثبّته (قد تحتاج إلى السماح بـ«التثبيت من مصادر غير معروفة»).
3. في أول استخدام للمحرّك دون اتصال، يُنزَّل النموذج (~870 ميغابايت).

### ويندوز
1. نزّل مُثبِّت `.msi` أو `.exe` من [**Releases**](../../releases).
2. شغّل المُثبِّت وافتح Wergêr.

## 🛠️ البناء من المصدر

### أندرويد (Gradle)
```bash
# APK للتصحيح
./gradlew :app:assembleDebug

# APK للإصدار (غير موقّع)
./gradlew :app:assembleRelease
```
المتطلبات: **JDK 17**، Android SDK (API 34)، build-tools 34/35.
الناتج: `app/build/outputs/apk/debug/app-debug.apk`

### ويندوز (Tauri)
```bash
cd desktop
npm install
npx tauri build
```
المتطلبات: **Rust** (1.77+)، **Node.js**، ومتطلبات Tauri 2.

> 💡 محرّك ONNX دون اتصال على سطح المكتب اختياري:
> `npx tauri build -- --features offline`
