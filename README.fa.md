## 🌍 Wergêr چیست؟

**Wergêr** (به کردی: _«مترجم»_) یک برنامهٔ ترجمهٔ **رایگان** و **متن‌باز** است که توسط [**Cybergah Group**](https://cybergah.com) ساخته شده است. هم **آفلاین** و هم **آنلاین** کار می‌کند و روی **اندروید** و **ویندوز** در دسترس است.

هدف ما ساده است: ارائهٔ ترجمهٔ باکیفیت برای زبان **کردی** و بسیاری زبان‌های دیگر — بدون هزینه، بدون تبلیغات، بدون ردیابی داده.

---

## ✨ ویژگی‌ها

- 📝 **ترجمهٔ متن** — کلمه‌ها، جمله‌ها و پاراگراف‌ها
- 📄 **ترجمهٔ سند** — فایل‌های `.txt` و `.pdf`
- 📷 **ترجمهٔ عکس** — OCR (خواندن متن از تصویر)
- 🔊 **گفتار (TTS)** — خواندن ترجمه‌ها با صدا
- 🔁 **جابه‌جایی زبان‌ها** — وارونه‌کردن مبدأ و مقصد با یک لمس
- 📶 **آفلاین** — پس از دانلود مدل بدون اینترنت کار می‌کند
- 🌐 **آنلاین** — از طریق LibreTranslate (نشانی قابل تنظیم)
- 🆓 **رایگان و متن‌باز** — همیشه، برای همه

## 🔌 آفلاین & آنلاین

دو موتور ترجمه وجود دارد:

### موتور آفلاین — NLLB-200
- مدل: **Meta NLLB-200 distilled 600M** (`facebook/nllb-200-distilled-600M`)
- قالب: **int8 ONNX** (کوانتیزه‌شده، نسخهٔ Xenova)
- اجرا: **ONNX Runtime** روی دستگاه (CPU)
- توکنایزر: **توکنایزر NLLB BPE** به‌طور کامل با Kotlin/Rust خالص بازنویسی شده — بدون کتابخانهٔ native، ۱۰۰٪ آفلاین
- مدل (~**۸۷۰ مگابایت**) یک‌بار در پوشه‌ای به نام **Wergêr** (یا پوشهٔ انتخابی کاربر، به‌صورت خودکار شناسایی می‌شود) دانلود می‌شود. پس از آن برنامه **بدون اینترنت** کار می‌کند.

### موتور آنلاین — LibreTranslate
- نشانی قابل تنظیم [LibreTranslate](https://libretranslate.com/)
- برای کسانی که نمی‌خواهند مدل را دانلود کنند

## 📥 نصب

### اندروید
1. آخرین APK را از [**Releases**](../../releases) دانلود کنید.
2. فایل `.apk` را باز و نصب کنید (ممکن است لازم باشد «نصب از منابع ناشناس» را فعال کنید).
3. نخستین بار که موتور آفلاین را به‌کار می‌برید، مدل (~۸۷۰ مگابایت) دانلود می‌شود.

### ویندوز
1. نصب‌کنندهٔ `.msi` یا `.exe` را از [**Releases**](../../releases) دانلود کنید.
2. نصب‌کننده را اجرا و Wergêr را باز کنید.

## 🛠️ ساخت از منبع

### اندروید (Gradle)
```bash
# APK دیباگ
./gradlew :app:assembleDebug

# APK انتشار (بدون امضا)
./gradlew :app:assembleRelease
```
پیش‌نیازها: **JDK 17**، Android SDK (API 34)، build-tools 34/35.
خروجی: `app/build/outputs/apk/debug/app-debug.apk`

### ویندوز (Tauri)
```bash
cd desktop
npm install
npx tauri build
```
پیش‌نیازها: **Rust** (1.77+)، **Node.js** و پیش‌نیازهای Tauri 2.

> 💡 موتور آفلاین ONNX روی دسکتاپ اختیاری است:
> `npx tauri build -- --features offline`
