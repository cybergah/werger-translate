## 🌍 Wergêr چییە؟

**Wergêr** (بە کوردی: _«وەرگێڕ»_) ئەپێکی وەرگێڕانی **بەخۆڕایی** و **سەرچاوەکراوەیە** کە لەلایەن [**Cybergah Group**](https://cybergah.com) دروستکراوە. هەم بە شێوەی **ئۆفلاین** و هەم **ئۆنلاین** کار دەکات، و لەسەر **ئەندرۆید** و **ویندۆز** بەردەستە.

ئامانجمان سادەیە: وەرگێڕانی بەکوالیتی بۆ زمانی **کوردی** و چەندین زمانی تر دابین بکەین — بێ پارە، بێ ڕیکلام، بێ بەدواداچوونی داتا.

---

## ✨ تایبەتمەندییەکان

- 📝 **وەرگێڕانی دەق** — وشە، ڕستە و پەرەگراف
- 📄 **وەرگێڕانی بەڵگەنامە** — فایلی `.txt` و `.pdf`
- 📷 **وەرگێڕانی وێنە** — OCR (خوێندنەوەی دەق لە وێنە)
- 🔊 **دەنگ (TTS)** — دەق بە دەنگ بخوێنەرەوە
- 🔁 **گۆڕینی زمانەکان** — بە یەک پەنجە سەرچاوە و ئامانج بگۆڕە
- 📶 **ئۆفلاین** — دوای داگرتنی مۆدێل بێ ئینتەرنێت کار دەکات
- 🌐 **ئۆنلاین** — لە ڕێگەی LibreTranslate (ناونیشان ڕێکدەخرێت)
- 🆓 **بەخۆڕایی و سەرچاوەکراوە** — هەمیشە، بۆ هەمووان

## 🔌 ئۆفلاین & ئۆنلاین

دوو بزوێنەری وەرگێڕان هەن:

### بزوێنەری ئۆفلاین — NLLB-200
- مۆدێل: **Meta NLLB-200 distilled 600M** (`facebook/nllb-200-distilled-600M`)
- فۆرمات: **int8 ONNX** (کوانتایزکراو، mirror لە Xenova)
- جێبەجێکردن: **ONNX Runtime** لەسەر ئامێر (CPU)
- تۆکنایزەر: **تۆکنایزەری NLLB BPE** بە تەواوی بە Kotlin/Rust لە نوێوە نووسراوەتەوە — کتێبخانەی native نییە، ١٠٠٪ ئۆفلاین
- مۆدێل (~**870 MB**) جارێک داگیردەکرێت بۆ فۆڵدەرێک بە ناوی **Wergêr** (یان ئەو فۆڵدەرەی هەڵتدەبژێرێت، بەشێوەی ئۆتۆماتیک دۆزراوەتەوە). دواتر ئەپ **بێ ئینتەرنێت** کار دەکات.

### بزوێنەری ئۆنلاین — LibreTranslate
- ناونیشانی [LibreTranslate](https://libretranslate.com/) کە ڕێکدەخرێت
- بۆ ئەو کەسانەی نایانەوێت مۆدێل داگرن

## 📥 دامەزراندن

### ئەندرۆید
1. نوێترین APK لە [**Releases**](../../releases) داگرە.
2. فایلی `.apk` بکەرەوە و دایمەزرێنە (لەوانەیە پێویست بێت ڕێگە بە «دامەزراندن لە سەرچاوەی نەناسراو» بدەیت).
3. یەکەم جار کە بزوێنەری ئۆفلاین بەکاردێنیت، مۆدێل (~870 MB) داگیردەکرێت.

### ویندۆز
1. دامەزرێنەری `.msi` یان `.exe` لە [**Releases**](../../releases) داگرە.
2. دامەزرێنەرەکە جێبەجێ بکە و Wergêr بکەرەوە.

---

## 🛠️ بنیادنان لە سەرچاوەوە

### ئەندرۆید (Gradle)
```bash
# APK ـی Debug
./gradlew :app:assembleDebug

# APK ـی Release (واژۆنەکراو)
./gradlew :app:assembleRelease
```
پێداویستی: **JDK 17**، Android SDK (API 34)، build-tools 34/35.
ئەنجام: `app/build/outputs/apk/debug/app-debug.apk`

### ویندۆز (Tauri)
```bash
cd desktop
npm install
npx tauri build
```
پێداویستی: **Rust** (1.77+)، **Node.js**، و پێشمەرجەکانی Tauri 2.

> 💡 بزوێنەری ئۆفلاینی ONNX لەسەر دێسکتۆپ بە ئارەزوومەندانە دەکرێتەوە:
> `npx tauri build -- --features offline`
